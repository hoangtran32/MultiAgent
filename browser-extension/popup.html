Dùng tài khoản chatbot đã đăng nhập; extension nhận diện website/model từ tab bạn chọn. Mở một chat mới trống trên mỗi website và chọn model trước khi kết nối. Mở Hub và cài cầu nối trình duyệt trước.

Đang đọc trạng thái…

Tự quét khung chat, nút gửi và nhãn model khi mở tiện ích.

Model được đọc từ giao diện hoặc luồng phản hồi khi website công khai. Chưa đọc được thì Hub ghi rõ chưa nhận diện, không gán model mặc định. Chọn model tại website; quota theo tài khoản đó.

Bộ chọn CSS nâng cao

Để trống để tự quét. CSS bạn nhập được ưu tiên; bấm Tự quét lại để bỏ CSS ô nhập/nút gửi cũ. Các bộ chọn nội dung phản hồi vẫn được giữ.

Các phiên web đã liên kết

Gateway API: sau khi liên kết, gửi một tin văn bản đầu tiên trên web với model đã chọn. Extension nhận diện giao thức trong phiên đó; mở Gateway & tài khoản web trong Hub để thêm tài khoản/model. Không tự đổi sang quota CLI. Adapter thử nghiệm có thể cần xác minh trên website.

Mỗi chatbot dùng một tab riêng. Chat đã gắn tiếp tục dùng được trong phiên; không cần kết nối lại sau mỗi lượt. Để tiếp tục chủ đề cũ, mở lịch sử Hub rồi gắn một chat web mới, Hub sẽ gửi ngữ cảnh. Giữ tab mở; tải lại hoặc chuyển chat sẽ ngắt kết nối. Tiện ích không xóa lịch sử, nội dung bạn đang gõ hay xuất cookie, mật khẩu, token đăng nhập ra Hub.
